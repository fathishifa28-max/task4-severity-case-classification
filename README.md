
# Pharmacovigilance – Task 4

## Severity & Case Classification

This repository contains my Task 4 submission for the pharmacovigilance internship.

### Objective

To classify adverse drug reactions according to:

- Seriousness
- Expectedness
- Clinical impact

### Cases Evaluated

1. Amoxicillin – Skin rash and itching
2. Ibuprofen – Gastrointestinal bleeding
3. Metformin – Lactic acidosis
4. Paracetamol – Mild nausea
5. Penicillin – Anaphylactic reaction

### Repository Contents

- `ADR_Severity_Classification.md` – Complete classification and rationale
- `Case_Analysis.md` – Individual case analysis

## Conclusion

The analysis demonstrates the application of pharmacovigilance principles to determine the seriousness, expectedness, and clinical impact of reported adverse drug reactions.
